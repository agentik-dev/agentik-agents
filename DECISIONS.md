### The API lane

1. **The API lane.** The API lane, the fanout verb and the api verbs of agentik-agents, is off unless the one file in the account's own home turns it on. A shard runs on the API key alone, behind the wall, and reads only, unless its type is a writing type, which the user file enables for the repos it lists and which writes one new worktree that the lane commits and never pushes. The two ceilings, one per fan-out and one per day, guard against an accident, and the Console's spending limit is the wall on money. A session with live shards reports their count by type. (2026-11-24; the owner's answer to decision 1, the owner's answer to hq's decision 81 on 2026-11-24)

2. **The bar that retires the older fan-out tool.** The older fan-out tool that scripts/measure compares the lane with is retired once two clean cards, run at least a week apart, each show no leak where the older tool holds, answers within one, and a median cost a shard within a quarter on the same model. Its checkout stays until 2026-12-31 whatever the cards say. (2026-11-26; the owner's answer to decision 2, the owner's answer to hq question 82, given in hq sitting 2026-11-25-1's one batch)
